# SatLink Share PRO

نقل ملفات سريع بين **الهاتف ↔ الهاتف ↔ الحاسبة** بدون إنترنت — على الراوتر أو **بدون راوتر**.

**المطور: مهند سات لنك**

| | Android | Windows |
|---|---|---|
| الإصدار | 3.1 | 4.1 |
| الواجهة | زر إرسال وزر استلام فقط (نيون) | نفس الستايل والأزرار |
| العمل بالخلفية | خدمة إرسال وخدمة استلام مع إشعار | بجوار الساعة (Tray) |

## المميزات

- **بالراوتر أو بدون راوتر:** شاشة «استلام» تشغّل الاستلام على الراوتر، وتنشئ بنفس الوقت «شبكة SatLink» (شبكة Wi‑Fi Direct خاصة مثل شبكة وهمية). الهاتف المرسل يكتشفها ويتصل بها تلقائياً بدون كتابة IP، والحاسبة تتصل بها من الواي فاي بالاسم وكلمة المرور الظاهرة بالهاتف.
- **سرعة أعلى:** قفل Wi‑Fi عالي الأداء أثناء النقل، ومخازن 512KB–4MB، وإعادة محاولة تلقائية تكمل من آخر بايت عند انقطاع الاتصال.
- **إكمال بالخلفية:** الإرسال والاستلام يستمران عند الخروج من التطبيق أو إطفاء الشاشة، مع شريط تقدم في الإشعار وزر إلغاء.
- **واجهة بسيطة:** الرئيسية فيها «إرسال» و«استلام» فقط. صفحة الإرسال تعرض الأجهزة والملفات المرسلة، وصفحة الاستلام تعرض الملفات المستلمة (الضغط على الملف المكتمل يفتحه).
- **تأكيد الاستلام:** المرسل لا يكتب «اكتمل» إلا بعد ما المستلم يحفظ الملف فعلاً، والملفات المتعددة (فيديو، تطبيقات، ألعاب) تكمل وحدة بعد الثانية حتى لو انقطع الاتصال، بدون نسخ مكررة.
- إرسال ملفات متعددة أو مجلد كامل بمجلداته الفرعية، وملفات أكبر من 40 GB، واستئناف الملف الناقص.
- مشاركة الملفات من أي تطبيق: مشاركة ← SatLink.

## طريقة الاستخدام

1. على الجهاز المستلم اضغط **استلام**.
2. على الجهاز المرسل اضغط **إرسال**، اختر الملفات، ثم اضغط على اسم الجهاز المستلم — يبدأ الإرسال فوراً.
   - «عبر الراوتر» = الجهازان على نفس الواي فاي.
   - «بدون راوتر · شبكة SatLink» = يتصل الهاتف مباشرة بجهاز الاستلام.
3. **الحاسبة بدون راوتر:** اتصل من واي فاي الحاسبة بشبكة `DIRECT-SL-SatLink-…` الظاهرة في شاشة استلام الهاتف، أو شغّل «نقطة الاتصال» في Windows واجعل الهاتف يتصل بها.

الملفات تُحفظ في `Downloads/SatLink Share PRO/Received` (في الحاسبة يمكن اختيار قرص آخر).

## البناء

### تلقائياً عبر GitHub Actions (الأسهل)
ارفع المشروع إلى GitHub، وكل `push` يبني:
- `SatLink-Share-PRO.apk` للأندرويد
- `SatLink Share PRO PC x64.exe` و `SatLink Share PRO PC x32.exe` للويندوز

تجدها في تبويب **Actions** ← آخر تشغيل ← **Artifacts**. ولإصدار رسمي: أنشئ tag يبدأ بـ `v` (مثل `v3.0`) فتُنشر الملفات تلقائياً في **Releases**.

### يدوياً
- **Android:** افتح مجلد `Android` في Android Studio (JDK 17، SDK 35) ثم Build ← Build APK. أو من الطرفية: `cd Android && ./gradlew assembleDebug`.
- **Windows:** ثبّت Python 3.10–3.14 ثم شغّل `PC/build.bat`. الناتج في `PC/dist`. للتشغيل من المصدر: `PC/run.bat`.
- **الاختبارات:** `python -m unittest discover -s tests`

> ملف APK الناتج نسخة debug للتجربة. للنشر على Google Play تحتاج توقيع release بمفتاحك الخاص.

## هيكل المشروع

```
Android/   تطبيق الأندرويد (Java، بدون مكتبات خارجية)
PC/        برنامج الويندوز (Python + Qt)
tests/     اختبارات البروتوكول
.github/   بناء APK و EXE تلقائياً
```

## ملاحظات

- البروتوكول متوافق مع النسخ السابقة (Android 2.7 / PC 3.9) على المنفذ 8988 (TCP) و 8989 (UDP).
- «شبكة SatLink» تحتاج Wi‑Fi Direct وصلاحية «الأجهزة القريبة» (أو الموقع في أندرويد 12 وأقدم). الاتصال التلقائي بدون نافذة موافقة يعمل على أندرويد 10+؛ الأقدم قد يطلب الموافقة على جهاز الاستلام.
- اسم الشبكة وكلمة المرور يُعلنان للأجهزة القريبة حتى يتصل المرسل تلقائياً، والاستلام يقبل أي جهاز متصل أثناء تشغيله؛ أوقف الاستلام عند عدم الحاجة.
